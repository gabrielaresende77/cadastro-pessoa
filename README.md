# Cadastro de Pessoas

Projeto desenvolvido em **Java** para a disciplina de **Programação I**, com uma interface gráfica para cadastro e gerenciamento de pessoas.

## Funcionalidades

* Cadastro de pessoas
* Visualização e navegação entre registros
* Alteração de pessoas
* Exclusão de pessoas com confirmação

## Tecnologias

* Java
* NetBeans
* Java Swing
